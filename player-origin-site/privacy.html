Information processed

When a user chooses to connect a Google account and approves YouTube access, ChannelOnly requests an OAuth access token and reads that account's YouTube subscription list and public channel-upload metadata to create a filtered feed. If the user requests a subscription change, ChannelOnly sends that change to the user's YouTube account. The app does not provide a separate ChannelOnly account and does not read the user's Gmail inbox.

How information is used

Information is used to obtain the Google-authorized YouTube access needed to display recent uploads from subscribed channel IDs, search for channels on request, and execute subscription changes the user explicitly requests.

Storage and sharing
