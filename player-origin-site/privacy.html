Information processed

Firebase Authentication processes the email address and authentication records needed to secure a ChannelOnly account. If a user separately authorizes YouTube, ChannelOnly reads the user's subscription list and public channel upload metadata to create a channel-filtered feed. If the user asks to subscribe or unsubscribe, ChannelOnly sends that change to the user's YouTube account.

How information is used

Information is used to authenticate the user, search for channels on request, display recent uploads from subscribed channel IDs, and execute subscription changes the user explicitly requests.
